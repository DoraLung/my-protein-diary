# 我的蛋白日記

繁體中文個人蛋白質追蹤網站，使用純 HTML、CSS、JavaScript，無框架、套件或付費 API。

## 使用

直接用瀏覽器開啟 `index.html`，不需安裝或執行伺服器。

## 功能

- 設定每日蛋白質目標、記錄餐點、編輯與刪除紀錄。
- 32 項內建食物與餐點估算，半份、一份與兩份換算。
- 手動新增的食物自動加入常用餐點。
- 七天攝取量圖表、JSON 備份匯出與匯入。
- 台灣時間晚上 22:00 的達標愛心與未達標提醒動畫。
- 當天沒有用餐紀錄時的動畫提醒。
- 兩天簡報用示範數據與动画，不写入真实纪录。

## 資料與提醒

飲食紀錄儲存在目前瀏覽器的 localStorage，不會同步到 GitHub。清除瀏覽器資料前請先匯出備份。

動畫提醒只在網頁開啟時執行。晚上 22:00 後首次開啟會檢查當天數據，每天通知一次。

基本食物採[國健署 2019 食物代換表](https://802.mnd.gov.tw/815/files/uploads/%E9%A3%9F%E7%89%A9%E4%BB%A3%E6%8F%9B%E8%A1%A82019.pdf)，複合餐點採網站明示的示範配方。估算值不是店家實測值，品牌食品請依營養標示調整。
